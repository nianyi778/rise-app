# Rise 瑞

> 别让紧急的事，埋掉重要的你。

Rise 是一款面向中国打工人（25-35岁）的 AI 目标教练微信小程序。帮助用户守护「重要但不紧急」的 Q2 目标——那些一直想做、却总被日常紧急事务淹没的人生大事。

## 产品概览

### 核心机制
1. **AI 理解目标** — 用户描述想做的事，AI 识别 Q2 属性并拆解执行方案
2. **每日一件事** — 每天生成一个 25 分钟可完成的具体行动
3. **专注 + 打卡** — 完成后记录心情，AI 温暖复盘
4. **周报守护** — 每周日生成个人化周报，看见自己的成长

### 设计风格
- iOS 毛玻璃美学（backdrop-filter blur）
- 暖奶油 × 深藏青 × 暖橙配色
- 全自定义 SVG 图标系统（无 emoji 图标）
- 品牌图标：地平线升起的太阳

### 商业化

## 技术栈（计划）

- **前端**：微信小程序原生
- **后端**：微信云开发（CloudBase）
- **AI**：Claude Haiku 4.5（高频）+ Claude Sonnet 4.6（质量）
- **推送**：微信订阅消息
